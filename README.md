# Linktree sencillo

Página estática minimalista para compartir enlaces de redes.

## Estructura

- `index.html`
- `styles.css`

## Editar enlaces

Abre `index.html` y cambia los `href` de:

- YouTube
- TikTok
- Twitch
- GitHub

## Deploy en Vercel

1. Sube este proyecto a un repositorio en GitHub.
2. Entra en Vercel y elige **Add New Project**.
3. Importa el repositorio.
4. Vercel detecta sitio estático automáticamente y publica.

## Deploy en GitHub Pages

1. Sube este proyecto a GitHub.
2. Ve a **Settings > Pages**.
3. En **Source**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Guarda y espera el enlace público.
